# Security at Xavum Sports

If you think you have found a security issue in anything we run, please tell us privately. Don't open a public issue.

Report it through GitHub's private reporting on the affected repository (Security tab, Report a vulnerability), or email marinto@xavumsports.com.

Please include what you found, the steps to reproduce it and the impact you expect. We'll reply as soon as we can and keep you updated while we fix it.
